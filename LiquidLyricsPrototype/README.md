# Liquid Lyrics · 网易云桌面伴侣

原生 Swift/SwiftUI + AppKit，最低 macOS 26。网易云负责音频播放，本应用只负责歌曲信息、歌词与播放控制。

## 构建运行

需要 Xcode 26+（Swift 6.2+）和 CMake。没有 npm / Node 依赖。

```sh
cd LiquidLyricsPrototype
./run.sh
```

输出 `.build/Liquid Lyrics.app`。脚本构建固定版本的 MediaRemote helper、编译 Swift Release、打包完整许可证并本机签名。重复构建前请从菜单栏退出旧应用；正式分发还需要 Developer ID 签名和公证。

```sh
swift test
```

打开网易云并选择歌曲，伴侣自动连接。设置 → 窗口 →“收起到菜单栏”可隐藏全部窗口并保持后台同步；菜单栏 →“显示播放器”恢复。右键窗口或点菜单栏的歌词气泡图标进入设置。空格播放/暂停，⌘← / ⌘→ 切歌（窗口获得键盘焦点时）。

## 已实现

- `PlaybackProvider` 与 `LyricsProvider` 分离。网易云读取兼容容器路径及 Application Support 路径。
- macOS 系统播放时钟优先，严格核对所属应用、标题与时长；本地只读状态补全歌曲 ID、歌手、专辑与封面。系统数据缺失时回退本地状态与 CoreAudio 活动判断。
- 系统播放控制 / 网易云 AX 菜单控制；Seek 能力检测，进度拖动和点击歌词跳转。
- 网易云 YRC → 网易云 LRC → LRCLIB → 本地 LRC。标题、歌手和时长 ±3 秒过滤搜索结果；确切歌曲 ID 直接请求。
- LRC 多时间标签、CRLF、文件 Offset；YRC 毫秒词时间、括号文本；逐字高亮、源提供的翻译/罗马音。不把推算出的逐字时间冒充真实时间。
- 7 天原子磁盘缓存（`~/Library/Caches/LiquidLyrics/v1`），歌曲切换取消旧请求，失败继续回退。“重新获取歌词”绕过缓存。
- `~/Music/LiquidLyrics/歌手 - 歌名.lrc` 本地歌词；设置中也可针对当前歌手动导入并立即采用。
- 自动跟随、手动滚动浏览、“回到当前”、点击 Seek 与 Offset 反向补偿。
- 官方 `.glassEffect` / `GlassEffectContainer` / `.glass` / `.glassProminent`；不使用 Material、普通 Blur 或 Shader 模拟玻璃。专辑渐变仅作装饰染色，玻璃仍由系统提供。
- 44pt 旋转封面，暂停停止，遵从减少动态效果。封面只提取低饱和强调色，普通歌词保持系统语义文字色。
- 280×380 至 420×600 缩放、圆角、位置/大小记忆、屏幕范围恢复、置顶、跨 Space、鼠标穿透、菜单栏、纯歌词模式。
- 设置：字号、中文字体、歌词间距（2–20pt，默认8pt）、行数/自动、对齐、窗口不透明度、翻译、罗马音、旋转、动态取色、Offset。中文字体提供系统默认、苹方、华文宋体、华文楷体、手札体、翩翩体，按本机可用字体显示并支持即时预览。自动模式按文字实际高度排列，不再拉伸短句行距。

鼠标穿透只影响悬浮窗口，菜单栏和设置仍可关闭它；重启自动解除穿透。纯歌词模式从顶部细空白区拖动。完整播放器从封面/歌名区拖动。

## 边界

MediaRemote 属于私有兼容接口，网易云本地数据格式也可能变化。本机已实测 26.6 + 网易云 3.1.13；其他版本需要回归。AX 控制需要用户在系统设置授予本应用辅助功能权限，本应用不会自动修改权限。不同网易云版本可能不公开可写进度，系统接口也不可用时禁用 Seek。

翻译/罗马音仅显示歌词源已有内容。歌词缓存不等于离线音乐库；没有下载、解密或播放网易云音频。应用退出不终止网易云。

本次未完成 Apple Music / Spotify provider；接口已分离，不声称已支持这两个播放器。

### 专辑染色

设置中的“专辑配色 · 文字与梦幻渐变”会从封面采样主色与辅色，用于低饱和度渐变和同色系歌词。当前句与标题加深，深色模式使用浅色文字；关闭后恢复系统文字色与原生玻璃背景。

### 跟随网易云启动

设置 → 启动 → 跟随网易云启动：使用 Apple SMAppService 注册登录项，菜单栏进程通过 NSWorkspace 监听网易云启动/退出，自动显示/收起播放器。默认关闭，可在系统登录项管理授权；手动退出本应用后不再监听，重新打开恢复。移动或删除开发构建前请先关闭此选项。登录跨会话行为仍需实机注销后验证。

### 应用安装与菜单栏歌词

当前安装位置：`/Applications/Liquid Lyrics.app`。打开应用默认后台启动网易云（不会主动开始播放）；设置可关闭。菜单栏可只显示当前歌词句，支持仅菜单栏模式；长句截断、悬停显示完整句，偏移与桌面歌词一致。菜单中的“显示播放器”可退出仅菜单栏模式。

左下角提供顺序、列表循环、单曲循环和随机播放指令，使用网易云为当前系统媒体应用时的 MediaRemote 接口；尚无可靠模式回读，因此不显示虚假的选中状态。右下角可查看、搜索和刷新网易云本地当前队列，当前版本只读，不支持在此点选切歌。
