# 验证记录 · 2026-10-07

环境：macOS 26.6、Xcode 27.0、Apple Swift 6.4、网易云 3.1.13。部署目标 macOS 26。验证过程中未修改网易云数据文件、账号或系统安全配置。

## 已通过

- Release 构建、辅助 framework 的双架构构建、本机签名与完整 app 启动。
- 7 个 Swift Testing 用例：LRC 多标签/CRLF/Offset、YRC 绝对词时间与括号文字、严格歌手与 ±3s 匹配、暂停及边界时钟、旧 SSTable 不覆盖日志状态、网络失败源回退和正缓存、翻译对齐及 Seek Offset 反算。
- 本机网易云真实歌曲标题、完整歌手、封面、时长、进度读取；真实在线歌词返回并显示，非演示模式。检查了三首歌曲的缓存，均为网易云 LRC（分别 74、46、65 行），不把它们标为已实测 YRC。
- 从伴侣点击播放、暂停，系统返回正确状态；初版本地估算暂停误差被发现并改为系统时钟优先。修订后 UI 暂停位置 116.301814s 与独立 helper 返回值一致。
- 暂停状态点击歌词，系统进度实际变为 124.57s，伴侣随后显示 124.57s 并保持暂停。
- 上一首/下一首均真实切换网易云曲目；歌曲自然切换后更新曲目、封面、歌词，旧曲目内容未覆盖新曲目。
- 设置中的“收起到菜单栏”实测隐藏播放器和设置窗口；读取窗口列表确认窗口消失，同时进程仍运行。菜单栏保留“显示播放器”恢复入口。
- 设置窗口可打开，纯歌词模式开/关生效；穿透设置开/关有反馈，完整播放器可恢复。
- 原型阶段实测水平/垂直边缘缩放和自动行数变化；当前保留同一原生 resizable 与透明圆角窗口结构。

- 实机逐字 YRC 的逐词听感校准、多语种翻译/罗马音覆盖率；YRC 解析已通过合成用例，不能用此声称所有实机曲目都有逐字歌词。

## 已知实现边界

网络获取采用严格匹配，可能宁缺勿错。翻译/罗马音仅对源实际提供的数据展示。MediaRemote 使用固定版本私有 helper，有超时；致命调用失败后本次进程停止重试并回退本地读取，重启应用可重新探测。系统 get 轮询后用时间戳插值；尚未换成 stream 常驻观察。

尺寸设置行数仍受字号、翻译/罗马音行高和窗口实际高度约束，优先避免重叠。鼠标穿透重启后自动关闭，以便用户恢复交互。
