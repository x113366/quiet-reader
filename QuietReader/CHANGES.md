## 运行

```sh
npm ci
npm start
```

源码运行先安装 Python 3.10+，再执行 `npm run setup:analysis`，在本仓库创建 `.venv` 并安装词云依赖。解释器查找顺序为 `QUIET_READER_PYTHON`、仓库 `.venv`、系统 Python。应用包包含分析脚本和停用词，不包含 Python 解释器。缺少依赖时词云界面给出提示，其他阅读功能仍可使用。

```sh
python3 -m pip install -r analysis/requirements.txt
npm test
npm run test:features
npm run test:e2e
npm run pack -- --mac --arm64
```

## 数据

书籍状态沿用 Electron 的用户数据目录。`preferences.json` 保存命名主题及按天、按书阅读时长；`analysis/<书籍ID>/` 保存 `source.txt`、`analysis.json`、`keywords_for_wordcloud.txt` 和 `analysis_report.txt`。不混入原 dia 目录中其他书籍的已有结果。统计为前台停留时长，不推断视线或是否实际读完；异常强制退出可能丢失最后约 5 秒。

原始桌面 ZIP 与 dia 源文件均未修改。新源码位于此目录。

## 两套完整 UI

工具栏的「浅色 UI / 深色 UI」按钮切换整个应用的界面，选择保存在本机，重启后恢复。

- 深色：沿用原阅读器的深灰、低干扰视觉，覆盖书架、设置、统计和完整词云工作室。
- 浅色：沿用原「字有引力」的纸白、森林绿与编辑式布局，覆盖同一套完整功能。
- 切换风格时当前书籍同步使用相应的默认文字与背景色；已命名保存的自定义主题保留，可随时重新应用。
- 词云恢复原版完整页面：素材编辑、TXT 导入、词语权重/自由文本、六种形状、四组配色、字体与字重、透明背景、字号/间距/旋转、画布尺寸、快速风格、重新排版和 PNG 导出。
- 从书架也能进入独立词云工作室；从阅读中进入后，可点击「分析当前书籍」接入 Python 结果，再用原版工具继续设计。返回阅读器保持原位置，词云页不计阅读时长。
- 词云画布配色由原有画布工具独立控制，不因应用界面风格切换而改写已设计的作品。

## 选中复制、macOS 窗口与导入清洗

- 正文支持鼠标拖动选区、双击选词、拖到边缘自动滚动选择；⌘C 或右键「复制选中文字」复制原文，⌘A 选择全文。选区按原文位置保存，滚动重绘不会丢失。拖动选字不会触发中央菜单开关。
- macOS 使用系统原生红黄绿窗口按钮；纯净阅读隐藏按钮，显示菜单或进入书架/词云时恢复。Windows 继续使用原窗口控件。
- 词云配色改为侧栏内自适应网格，避免横向溢出；桌面布局中参数与画布独立滚动，窄窗口改为上下布局。
- 书架限制封面宽度、统一封面高度，长标题换行并截断，避免超长书名破坏排列。
- 选择或拖入 TXT 后先显示导入选项。清洗每次默认关闭，必须手动开启。
- 内置「下载站引流」「群聊与公众号推广」「求票与站点提示」三套可选方案，支持补充每行一条的自定义规则，保存上次所选方案及自定义规则。
- 精确匹配：删除包含指定文字的整行。模糊匹配：忽略标点、空格、大小写，允许一个字的增加、删除或替换。规则至少含 4 个有效字符，最多 50 条；超过 2000 字的正文长段落不参与整行删除。
- 启用清洗必须先预览，修改规则后需重新预览。显示每本书的命中总数、行号、命中规则及前 100 行样例。
- 原始 TXT 不改写。发生清洗时，将原始字节备份至用户数据目录的 `books/<书籍ID>.original.txt`，清洗后的阅读副本以 UTF-8 单独保存。关闭清洗可重新导入原版。

## 书评、TXT 导出与书架进度

- 书架卡片及阅读工具栏均可打开「书评」：0–5 星（0 为未评分）、最多 20 个标签、最多 10000 字评价。保存至每本书的本地状态，重启保留。
- 书架展示评分和标签，并显示进度条、百分比、已读字数 / 总字数。字数按 Unicode 字符统计，忽略空白；标点和英文字母计入。已读字数按当前阅读位置计算，返回更早位置会下降，不表示历史累计阅读量。滚动到底部计为 100%。旧书库首次打开自动补齐字数统计。
- 书架及阅读工具栏可「导出 TXT」，弹出原生保存对话框，导出当前阅读版本为 UTF-8；清洗后的书导出清洗后的副本。
- 阅读工具栏「搜索」或 ⌘F 打开全文搜索；支持精确、模糊匹配，点击结果跳转并高亮，支持上一处 / 下一处。
