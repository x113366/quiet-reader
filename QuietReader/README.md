# 静读 · Quiet Reader

完全本地的 TXT 小说阅读器，采用 Electron、JavaScript 和本地文件持久化。固定背景 #212121，默认正文 #888888，默认字号 22px、行距 1.9 倍、左右内边距 64px。段首缩进两字，段落之间至少一个完整空行。

## Windows 直接运行

将 `QuietReader-Windows-x64.zip` **完整解压**到任意目录，双击其中的 `Quiet Reader.exe`。不需要安装 Node.js。请保留解压后的全部文件，不要单独移动 EXE。应用包未签名。

## Windows / macOS 从源码运行

安装 Node.js 24 LTS。解压源码 ZIP，在 QuietReader 目录打开终端：

```sh
npm ci
npx install-electron --no
npm start
```

首次安装需要联网下载依赖和 Electron；阅读、导入、查找和保存全部离线。macOS 支持 Apple Silicon 与 Intel，安装依赖时自动选取本机架构。此交付未在 macOS 实机运行，也未生成 macOS 安装包。

## 简短使用说明

- **导入**：点击「导入」选择 TXT，或把 TXT 拖进窗口。自动识别 UTF-8、UTF-8 BOM 与 GB18030；乱码时在「设置」切换编码重新载入。切换编码会重置本书进度。
- **书库**：每本书保留本地原文件副本，以原始字节的 SHA-256 管理。相同文件重复导入合并；相同文件名但内容不同的书分别管理。
- **阅读**：鼠标滚轮、触控板和普通模式的滚动条均可连续滚动，无分页或行吸附。拖动底部进度条直接跳转到对应位置。
- **目录**：点击「目录」，自动识别常见的「第…章／节／卷／回」、序章、番外和 Chapter 标题。点击标题跳转；可以筛选章节，也可以拖动目录面板中的进度条。目录识别基于标题格式，非标准 TXT 可能需要用查找定位。
- **查找**：精确查找按原文匹配。模糊查找忽略空白、标点和大小写，三个字起容许一个字的增、删或替换。查找范围为单个段落，最多显示 200 个结果。点击结果跳转并高亮；Esc 清除高亮。
- **纯净**：点击「纯净」隐藏标题栏、工具栏、进度条和滚动条，只显示正文。按 Esc 返回，右键显示书库、目录、查找和设置菜单。拖动窗口顶部约 14px 的透明区域移动窗口。窗口四边、四角保留缩放能力。
- **置顶**：在「设置」勾选「窗口置顶」，或右键菜单切换。纯净模式与置顶状态按书保存。
- **排版与进度**：字号、行距、左右内边距、颜色、窗口尺寸及位置锚点按书自动保存。停止滚动约 500ms 后保存；连续阅读最长约 3 秒进行一次保存；切书和关闭也保存。

### 快捷键

macOS 使用 ⌘，Windows 使用 Ctrl。

| 操作 | 快捷键 |
| --- | --- |
| 导入 TXT | Ctrl / ⌘ + O |
| 书库 | Ctrl / ⌘ + L |
| 查找 | Ctrl / ⌘ + F |
| 目录与进度 | Ctrl / ⌘ + J |
| 纯净阅读 | Ctrl / ⌘ + Shift + P |
| 窗口置顶 | Ctrl / ⌘ + Shift + T |
| 退出纯净阅读 | Esc（先关闭已打开的面板） |

## 本地数据与备份

默认数据目录使用 Electron 的用户数据目录：Windows 通常是 `%APPDATA%/quiet-reader`，macOS 通常是 `~/Library/Application Support/quiet-reader`。其中 `books/` 保存原始 TXT、各书 JSON 状态及上一版 `.bak` 备份。关闭应用后复制整个数据目录即可备份。测试专用环境变量 `QUIET_READER_DATA` 可指定独立目录。

状态采用异步串行写入、临时文件落盘后原子替换，并保留上一版备份。原文锚点由段落编号、段内 UTF-16 字符偏移和显示行顶部的像素偏移组成；不同排版记录最多保留 20 份。改变排版而未主动改变阅读位置时，可恢复旧排版的精确位置；主动滚动、进度条、目录或查找跳转之后，以新位置为准。

单文件上限 32MB。正文在后台计算换行，使用紧凑行索引；前台只绘制可见行。极长内容超过浏览器滚动高度限制时映射滚动条，滚轮仍按像素移动。当前正文使用 Canvas 绘制，不支持鼠标划选整段正文或完整屏幕阅读器朗读。

## 维护与打包

```sh
npm run pack       # 生成当前平台的应用目录
npm run dist:win   # Windows 便携 EXE（需要额外下载 NSIS 工具）
npm run dist:mac   # 在 macOS 上生成 Intel 与 Apple Silicon DMG
```

macOS 的签名和公证应在 macOS 上配置 Apple 开发者证书后进行。源码包含手动触发的 GitHub Actions 工作流，可在 Windows 与 macOS 构建。Electron、electron-builder 和依赖版本通过 package-lock.json 固定；长期维护时应定期升级 Electron 安全版本。

源码结构：`src/main.cjs` 负责窗口、编码工作线程和持久化；`src/renderer.js` 负责阅读与交互；`src/layout-worker.js` 负责后台换行；`src/search-engine.js` 与 `search-worker.js` 负责查找；`src/core.cjs` 负责解码、正文结构和目录识别。

既有验证结果见 `VALIDATION.md`。本次新增目录、进度条、纯净窗口和置顶后，按用户「不要测试，打包给我」的要求直接打包，未执行新增功能测试。
